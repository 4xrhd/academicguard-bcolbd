# Model Training & Evaluation Documentation

AcademicGuard uses a multi-layered detection engine to identify traditional text plagiarism, multi-language code cloning, and AI-generated content in academic submissions.

---

## 1. Automated Model Training Pipeline (`auto_trainer.py`)

The system features an **Automated Model Training Pipeline** that allows instructors to refine detection accuracy over time by providing ground-truth labels.

### 1.1 Data Collection & Labeling
- **Sources**: Submissions manually annotated by instructors via the UI.
- **Labels**:
  - `Human` (`0`): Human-written authentic prose.
  - `Plagiarized` (`0`): Copied from another student (human-written).
  - `AI Generated` (`1`): Generated by frontier LLMs.
  - `Mixed` (`1`): Hybrid human + AI composition.
- **Trigger Condition**: Requires a minimum of 20 samples (at least 5 per class) to trigger training.

### 1.2 Feature Extraction
1. **Perplexity (GPT-2)**: Measures token-level predictability via cross-entropy loss.
2. **Burstiness**: Variance in perplexity across sentences.
3. **Stylometric Score**: Composite score incorporating Average Sentence Length (ASL), Type-Token Ratio (TTR), and Punctuation Density (PD).

### 1.3 Training & Validation Pipeline
- **Scaler**: `StandardScaler` to normalize feature magnitudes.
- **Classifier**: `LogisticRegression(L2, solver='lbfgs', max_iter=500)`.
- **Validation**: Stratified 5-fold cross-validation tracking ROC-AUC, Accuracy, Precision, Recall, and F1-Score.
- **Registry & Snapshots**: Updates `backend/models/model_registry.json` and creates timestamped backups in `backend/models/backups/`.
- **Hot-Swapping**: Loads the new model into memory immediately without restarting the API process.

## 2. Neural Code Clone Model Training (`UniXcoder` on `POJ-104`)

For semantic code clone forensics, AcademicGuard integrates a fine-tuned **UniXcoder** transformer model trained on the **Peking University Open Judge (POJ-104)** benchmark dataset (`scripts/train_unixcoder_poj104.py`):
- Encodes AST node tokens and normalized code sequences into 768-dimensional dense vectors.
- Evaluates deep semantic similarity across C, C++, Java, and Python.

## 3. Lab Report Evaluation & Multi-Engine Scoring

### Stage 1: Layout-Aware Extraction
- **OpenDataLoader-PDF**: Extracts structured Markdown, tables, and native code blocks.
- **PyMuPDF Fallback**: Layout coordinate-based text block sorting.

### Stage 2: Cross-Submission Text Plagiarism
- **Lexical TF-IDF**: Sublinear term-frequency cosine similarity (40% weight).
- **Semantic MiniLM**: 384-dimensional dense sentence embeddings (`all-MiniLM-L6-v2`, 60% weight).

### Stage 3: Code AST & UniXcoder Forensics
- Multi-language Tree-Sitter AST parsing + canonical alpha-renaming (`var0`, `var1`) + Subtree Isomorphism Kernel + UniXcoder embeddings.

### Stage 4: AI Content Detection & ESL Safeguards
- Evaluates GPT-2 perplexity, sentence burstiness, and stylometry.
- Enforces **Confidence Threshold Banding** ($p \in [0.40, 0.75]$ quarantine) to prevent false accusations against ESL students.

### Stage 5: Dynamic Risk Scoring
- **Profile A (`CODE_PRESENT`)**: $\text{Risk} = 0.35 \cdot \text{TextSim} + 0.35 \cdot \text{CodeSim} + 0.30 \cdot P_{\text{AI}}$
- **Profile B (`TEXT_ONLY`)**: $\text{Risk} = 0.50 \cdot \text{TextSim} + 0.50 \cdot P_{\text{AI}}$
